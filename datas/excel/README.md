# Excel exports

`RFOTO_ABC_Main_Results.xlsx` contains numerical experimental Tables 7–16.
`RFOTO_ABC_Supplementary_Statistics.xlsx` contains all revision metrics, paired contrasts and the separate objective-weight sweep.

All used cells have explicit white fills and black fonts. The workbooks use typed numbers, no color-coded meaning and no macros or external connections. Missing values are blank; diagnostic -1 retains its documented unavailable meaning. Long identifiers are kept as text. Display precision does not change stored values. Complex statistics are calculated by the Python analysis scripts, not spreadsheet formulas.

Source files, sample sizes and interpretation notes appear above each data table. Current CSV counterparts and their upstream mapping are in `../tables/`.
