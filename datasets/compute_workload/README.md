# Compute workload source

Only Alibaba Cluster Trace v2018 batch tasks, machine metadata and machine usage are used. Source schema and documentation are under `alibaba_cluster_trace_v2018/docs/`. The large raw archives are not checked in; acquisition, file sizes and SHA-256 values are documented in `../DATASET.md`.

The experiment-ready arrays and preprocessing metadata are in `../processed/`. The project does not claim these data-center records are measured radio traffic.
