# Reproduction utilities

- `core_runner.py`: four-group summaries and fresh replay on frozen input instances. Default mode is read-only with respect to archived data.
- `historical_suite.py`, `historical_replay.py`: historical algorithm/ablation/sensitivity/transfer/scaling protocols. The dispatcher writes separate timestamped outputs.
- `reanalyze.py`: recompute original paired tests and corrected best counts to `outputs/reanalysis/`.
- `build_tables.py`: rebuild numeric manuscript Tables 7–16 from unchanged recorded CSVs. It also writes the workbook JSON input under `outputs/`.
- `export_workbooks.mjs`: optional white/black Excel exporter, requiring `@oai/artifact-tool`. It performs rendering and error inspection. Standard Python reproduction does not require this authoring package; all numbers are available as CSV and the finished XLSX files are included.
- `preprocess_alibaba.py`: trace cleaning and reservoir sampling. Use an explicit local `--raw-dir` and a new `--output-dir`.
- `regenerate_figures.py`, `historical_figures.py`, `workload_figure.py`: regenerate manuscript scientific figures from recorded results/inputs in a separate output folder.
- `validate_release.py`: assert frozen inputs, records, figure DPI, Excel cell colors, table counts and release checksums.

The immutable revision optimizer, runner and protocol stay under `../experiments/revision_20260909/`. Runtime caches, workbook inspection previews and local outputs are not versioned. The current package manifest is generated by `validate_release.py --write-manifest` after verification.
